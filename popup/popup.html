How it works

  • Capture — pick Tab or Video, then press the big button. Selected region takes a drag or a hover-and-click on one element; the arrow keys nudge the box, Ctrl plus the arrows resizes it, Esc cancels.
  • Use last region repeats the box you cut on this site before.
  • Every floating source gets a row: Show alone fills the window with that one, Back to grid returns to the shared layout, Stop removes one, Stop all closes everything.
  • With two or more sources the window draws a label strip under each tile so you can tell them apart.
  • On a video page the control sits in the player bar; left-click floats the video, right-click opens the actions. The same actions live in Chrome's right-click menu.
  • Float button on this site puts the badge on the site you are looking at.
  • Shortcuts: Alt+Shift+P floats the tab, Alt+Shift+R starts a region, Alt+Shift+X stops everything. Video mode has no shortcut — that request needs a click.
  • Chrome can open PiP on its own when you leave a playing tab. PiPDesk closes that one again unless you asked for it.
